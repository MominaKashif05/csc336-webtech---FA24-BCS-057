## Project Overview
This project is a two-page static e-commerce website clone inspired by the official **Pandora** jewelry website (focusing specifically on the Marvel Collection). It is built strictly using HTML5, CSS3, Flexbox/Grid layouts, and Bootstrap 5 utilities, adhering strictly to the constraint of having **no JavaScript**.

## Reference Website
* **Brand:** Pandora
* **Target URL:** [https://us.pandora.net](https://us.pandora.net)

## Project Structure & Files
* `index.html`: The homepage featuring a full-width responsive hero video banner, a promotional section, and an 8-item Marvel collection product grid with responsive card alignments.
* `product.html`: The product detail page for the *Disney Marvel Doctor Doom Mask Charm*, featuring a vertical scrollable multi-image feed, pricing, product specifications, accordion dropdowns, and a consistent footer.
* `style.css`: The external stylesheet containing all custom layout rules, video scaling, and logo filter properties (maintaining a clean separation of concerns away from HTML).
* **Assets Folder / Directory:** Contains all branding files (`pandora_logo.png`), hero videos (`pandora_landing.mp4`), promotional images (`double_charms.png`), and product imagery (`doom_mask.jpg`, `loki_helmet.jpg`, etc.).
